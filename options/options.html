How Freemium Licensing Works

  1. Step 1: Stripe Checkout
    In the extension popup, click "Upgrade to Pro — $9.99". This opens the secure Stripe payment link.
  2. Step 2: Retrieve Session ID
    After completing payment, Stripe redirects to your success page with ?session_id=cs_... in the URL query string.
  3. Step 3: Activate
    Paste that session ID into the field above to activate Pro tier instantly across your browser.

Connecting a Real Cloudflare Worker Endpoint

The extension currently uses a swappable stub function verifyLicense(sessionId) in background/service-worker.js that accepts any non-empty string.

Cloudflare Worker Integration (service-worker.js)
// In background/service-worker.js -> verifyLicense(sessionId):
const res = await fetch(`https://your-worker.workers.dev/verify-license?session_id=${encodeURIComponent(sessionId)}`);
const data = await res.json();
if (data.valid) {
  await chrome.storage.local.set({ licenseStatus: 'pro', stripeSessionId: sessionId });
}
