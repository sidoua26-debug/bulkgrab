How Freemium Licensing Works

  1. Step 1: Coinbase Commerce Crypto Checkout
    In the extension popup, click "🪙 Pay with Crypto — $9.99". This opens the secure Coinbase Commerce payment checkout.
  2. Step 2: Retrieve Charge ID
    After completing payment, copy your Charge ID or 8-character charge code from your confirmation screen or email receipt.
  3. Step 3: Activate
    Paste your Charge ID into the field above to activate Pro tier. (Note: Blockchain confirmations typically take 2–5 minutes).

Connecting a Real Cloudflare Worker Endpoint

The extension currently uses a swappable stub function verifyLicense(chargeId) in background/service-worker.js that accepts any non-empty string.

Cloudflare Worker Integration (service-worker.js)
// In background/service-worker.js -> verifyLicense(chargeId):
const res = await fetch(`https://your-worker.workers.dev/api/verify-coinbase?charge_id=${encodeURIComponent(chargeId)}`);
const data = await res.json();
if (data.valid) {
  await chrome.storage.local.set({ licenseStatus: 'pro', coinbaseChargeId: chargeId });
}
