ZIP Archiving Permission

Enable Cross-Site ZIP Bundling

To package files hosted across external servers (such as GitHub, AWS S3, Google Cloud, or CDNs) into a single .zip archive, Chrome requires elevated host permissions.

🔍 What Chrome Will Show You

Chrome’s permission dialog will state: "Read and change your data on all websites".

Why: Chrome has no narrow "read-only downloads from external links" permission. To fetch binary files across different domains and bundle them into a ZIP, Chrome requires the <all_urls> permission.

Our Commitment: This permission lets BulkGrab read data from any site you visit while bundling files, but BulkGrab only reads the specific file URLs you select when you click 📦 ZIP. It never collects, tracks, or transmits your browsing data, history, or credentials.

This is a one-time request. If you decline, you can still download any file individually via Chrome’s standard download manager. You can also revoke this permission at any time in the Options page.
